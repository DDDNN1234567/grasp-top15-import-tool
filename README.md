# 管家婆辉煌 TOP15 双向直导工具

千业管理通/商贸通（Bas 旧版库）与管家婆辉煌 TOP15（标准账套）之间的**双向数据迁移工具**，
支持 Excel 通道与数据库直连通道，通过管家婆官方存储过程 + 批量直写，保证软件内正常显示。

## 一、功能总览

| 通道 | 方向 | 说明 |
|---|---|---|
| Excel 导入 | Excel → 管家婆 | 单位/商品/仓库/职员/期初库存/价格跟踪，编号自动数字化 |
| 正向直导 | 千业 Bas → 管家婆 | 级联数字化、官方存储过程、16 价格方案、当前结存库存 |
| 反向导出 | 管家婆 → 千业 Bas | 重建 BasePath、辅助单位、价格槽位、业务表 |
| 维护工具 | 单库 | 账套自检、备份、回滚、清缓存、差异对比 |

## 二、v3.0 改进清单（针对实机验收反馈）

1. **零预填**：所有连接参数（服务器/数据库/用户名/密码）初始全部为空，由用户按实际环境填写，不内置任何实例/账套。
2. **帮助弹窗**：每个功能按钮旁配“?”，点击弹出用途、前置条件与操作说明。
3. **步骤引导式界面**：各页签以“第 1 步、第 2 步……”卡片组织，按顺序操作即可；专业配色与卡片式布局。
4. **反向引擎修复（软件显示语义）**：
   - 通用 `build_basepath` 按真实层级重建 BasePath，不依赖编号大小；
   - 辅助单位空槽换算率正确写 0（不再误写 1）；
   - 16 个价格槽位（含用户自定义预设价格列）动态解析、一一对应；
   - 补全仓库、职员、当前结存库存；新增委托/受托、借进/借出业务表。
5. **正向引擎修复**：BFS 级联数字化（正确处理父编号大于子编号）；统一反开账并在完成后自动恢复；16 方案价格完整不遗漏。

## 三、快速开始

### 1. 环境要求
- Windows + SQL Server（2008 SP2 及以上，支持 2008/2012/2016/2019/2022，含 Express）。
- ODBC Driver 17（工具自动探测，回退 Native Client / SQL Server）。
- Python 3.8+ 运行源码；或直接使用打包好的 exe（免安装）。

### 2. 源码运行
```powershell
pip install pyodbc xlrd openpyxl
python gpj_top15_gui.py
```

### 3. 打包 exe
```powershell
python -m PyInstaller --noconfirm --clean --onefile --windowed --name "管家婆TOP15双向直导工具" `
  --hidden-import tkinter --hidden-import _tkinter `
  --hidden-import pyodbc --collect-submodules pyodbc `
  --add-data "<python>\Lib\tcl8.6;lib\tcl8.6" `
  --add-data "<python>\Lib\tk8.6;lib\tk8.6" gpj_top15_gui.py
```

### 4. 通用操作流程
1. 在对应页签填写连接参数，点“测试连接”确认可连通；
2. 按“第 1 步、第 2 步……”选择文件或勾选模块；
3. 点带★的主按钮执行，查看“执行日志”；
4. 完成后清客户端缓存并重新登录管家婆核对。

## 四、关于 .mdf / .ldf 文件

**不能把任意 .mdf/.ldf 直接双击导入管家婆。** 它们是 SQL Server 的数据库主文件/日志文件，不是通用交换格式，
普通进程无法直接解析。正确流程：

1. 先由 SQL Server 实例**附加（ATTACH）**为数据库；
2. 工具经 ODBC 连接该数据库，按 Bas 通用结构处理；
3. 执行双向直导。

约束：
- 高版本文件不能附加到低版本实例（如 2016 的库不能挂到 2008）；
- 仅识别千业商贸通 Bas 结构（Bas* 表），非该结构/加密/损坏/RECOVERY_PENDING 无法处理；
- 文件被占用时需先解除文件锁。

## 五、数据口径与边界

- **库存取当前结存**（StorageGoodsInfo），不是历史期初表 StorageIniGoods；
- 负库存若出现数量与金额异号，工具以数量符号按 |单价| 重算金额，需财务确认；
- 官方过程分配的 updatetag 为增量版本标记（>0 即合法），不强制统一 10000；
- 所有导入/导出前自动备份，可在维护工具中回滚。
